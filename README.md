# Leonida Atlas

Atlas interactif en français consacré à la reconstruction communautaire de la carte de **Grand Theft Auto VI**.

## Lancer localement

Le site est entièrement statique. Depuis ce dossier :

```bash
python3 -m http.server 8080
```

Puis ouvrir `http://localhost:8080`.

## Publier sur GitHub Pages

1. Créer un dépôt GitHub public.
2. Envoyer le contenu de ce dossier sur la branche `main`.
3. Dans **Settings → Pages**, choisir **Deploy from a branch**, branche `main`, dossier `/ (root)`.
